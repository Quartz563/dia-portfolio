Projects

  • Ironfolk Combat Inc Website

    The public website for a Wellington-based historical fencing club, which I built and maintain using server-rendered Phoenix, deployed to Fly.io. This project was designed with the goal of bringing a refreshed design and to attract new members to the client organisation.

    • Elixir / Phoenix
    • HTML / CSS / JS
    • Production

  • CoffeeSpy

    A crowdsourced coffee price tracker for Wellington cafes. A Flutter client talks to a Phoenix JSON API backed by PostgreSQL, with JWT authentication. The intended goal of this project was to begin to learn the basics of mobile development, while also learning more about how APIs can work in a production style server. It also serves as a fun idea to explore for Wellington specifically.

    • Flutter / Dart
    • Elixir / Phoenix
    • REST / JSON
    • PostgreSQL
    • JWT
    • Docker

  • Graph Visualiser

    A system to create and visually represent randomly generated connected graphs with pathfinding algorithms, with tests included. The intended outcome of this project was to put into practice an interesting idea I had developed regarding how to ensure a unique and self-contained graph can be generated, and to test it using pathfinding algorithms.

    • Java
    • Maven
    • JUnit
    • Object Orientated
